# Assets Folder

This folder contains the app assets:
- `icon.png` - App icon (1024x1024 px recommended)
- `splash.png` - Splash screen image (1284x2778 px recommended)
- `adaptive-icon.png` - Android adaptive icon (1024x1024 px recommended)
- `favicon.png` - Web favicon (48x48 px recommended)

## Creating Assets

You can use tools like:
- Canva
- Figma
- Adobe Illustrator

Create images with the noted dimensions and place them here with the exact filenames.

For quick testing, you can use placeholder images from:
- https://placeholder.com
- https://picsum.photos
